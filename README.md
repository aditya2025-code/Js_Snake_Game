# 🐍 JS Snake Game

This is my **first JavaScript game**, and I'm really excited to share it! I built this project to get hands-on with core JavaScript concepts like the game loops, and event handling — all wrapped up in the classic Snake game we all grew up playing.

🎮 **Play it live:** [jssnakegame67.netlify.app](https://jssnakegame67.netlify.app/)

## ✨ Features

- 🕹️ Classic Snake gameplay — move, eat, and grow
- ⌨️ Smooth keyboard controls for directional movement
- 💥 Collision detection (walls & self)
- 📈 Live score tracking as you play
- 🔁 Game over and restart functionality
- 🎨 Simple, clean UI built with HTML, CSS, and vanilla JavaScript

## 🧠 Concepts I Practiced

- JavaScript game loops using `setInterval` 
- Handling keyboard events for real-time input
- Managing game state (score, direction, game over conditions)
- DOM manipulation and basic UI updates
